## Périmètre

La documentation distingue trois niveaux :

- **fonctionnalités utilisateur** : ce que l'on peut faire dans Mathom ;
- **compatibilité** : ce qui doit rester lisible ou migrable depuis BasKet ;
- **implémentation** : noms internes, dépendances, construction et packaging.

Le dossier historique `doc/` reste présent car il est intégré au système de documentation KDE hérité de BasKet. Son contenu n'est pas supprimé : il sera progressivement adapté à Mathom lorsque le manuel embarqué sera repris.
